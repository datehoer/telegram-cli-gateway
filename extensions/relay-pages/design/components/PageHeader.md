# PageHeader

页头显示是哪个 Bot、什么时候发的、要读多久，再接文章标题。

- 结构：`.rp-header` > `.rp-avatar` + `.rp-who`（`.rp-bot` 显示名，`.rp-meta` 内多个 `<span>` 自动用「·」分隔），其后 `h1.rp-title`。
- 调用方提供：Bot 显示名、用户名、发布时间、预计阅读时长（按 400 字/分钟估算，向上取整）、标题。头像有图就放 `<img>`，没有就放显示名首字母（`sky` 底 + `on-sky` 字）。
- 标题取 Markdown 第一个 `# ` 标题并从正文中移除；没有时用正文首行前 40 个字。
- 不要在页头放操作按钮，操作统一放 PageFooter。
