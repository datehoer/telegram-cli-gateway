# PageFooter

页脚：来源、过期时间、原文入口和回到对话的按钮。

- 调用方提供：Bot 用户名、过期时间（「7 天后过期」/「永久保存」）、原始 Markdown 地址（`/raw`）、回到对话的深链（`tg://resolve?domain=<bot>` 或 `https://t.me/<bot>`）。
- 主按钮「返回对话」用 `.rp-btn-primary`，每页只有这一个主按钮；「复制全文」复制原始 Markdown。
- 两个按钮同为默认尺寸（36px），主按钮放在右边。容器宽度 ≤520px（手机、Telegram 内置浏览器）时说明文字在上，两个按钮各占一半宽、44px 高。页脚依赖外层 `.rp-card`（或 `.rp-container`）作为尺寸容器。
- 页面已过期时整个卡片只保留页头和一句「此内容已过期」，页脚保留「返回对话」。
